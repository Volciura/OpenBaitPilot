# OpenBaitPilot

**OpenBaitPilot** — проект открытого автопилота для прикормочного радиоуправляемого кораблика на базе **STM32**.

Цель проекта — сохранить привычное ручное управление с аппаратуры FlySky и добавить GPS-навигацию, сохранение точек и автономное движение по маршрутам. Автопилот проектируется так, чтобы основные функции управления и безопасности не зависели от Wi-Fi, смартфона или эхолота.

> **Статус:** проектирование и подготовка прошивки. Репозиторий находится на ранней стадии; готовая к эксплуатации прошивка пока не заявлена.

## Архитектура системы

Система разделена на три самостоятельных проекта:

| Репозиторий | Платформа | Назначение |
| --- | --- | --- |
| **OpenBaitPilot** (этот репозиторий) | STM32 | Автопилот, GPS, приём команд RC, управление двигателем и сервоприводами, безопасность |
| **OpenBaitPilotWiFiBridge** (планируется) | ESP32 | Связь с Android, передача команд и телеметрии, интеграция с эхолотом |
| **OpenBaitPilotAndroidApp** (планируется) | Android | Карта, точки, маршруты, телеметрия и перспективное отображение данных эхолота |

```text
             FlySky FS-i6
                   │
              Приёмник IA10B
                   │
                   ▼
GPS ───────────► STM32 ─────────► ESC / двигатель
                   │ └─────────► Сервоприводы / вспомогательные выходы
                   │
             интерфейс TBD
                   │
                   ▼
                 ESP32 ◄──────► Эхолот (планируется)
                   │
                 Wi-Fi
                   │
                   ▼
             Android-приложение
```

**GPS подключается непосредственно к STM32.** ESP32 выступает шлюзом связи, а не навигационным контроллером.

## Известное оборудование

| Компонент | Модель / характеристика |
| --- | --- |
| Передатчик | FlySky FS-i6 |
| Приёмник | FlySky IA10B |
| Двигатель | Бесколлекторный 4250, 800 KV |
| Регулятор | Flycolor 120 A |
| Ходовой аккумулятор | 3S |
| Корпус кораблика | Около 80 см, полезная нагрузка до 2 кг |
| Контроллер автопилота | STM32, точная модель уточняется |
| GPS | Модуль и интерфейс уточняются |

Переход на 4S рассматривался, но пока **не планируется**. Конкретные выводы контроллера, напряжения питания и схемы подключения должны быть проверены до реализации аппаратно-зависимого кода.

## Планируемые функции

- **Ручной режим:** управление корабликом с передатчика.
- **Сохранение точки:** фиксация GPS-координат по команде с передатчика.
- **Автопилот:** движение к выбранной точке и в дальнейшем по маршруту.
- **Телеметрия:** передача навигационного состояния и служебных данных через ESP32.
- **Безопасность:** обработка потери RC-сигнала, недостоверного GPS, сбоев связи и переключения режимов.
- **Дальнейшее развитие:** возврат домой, автоматическое обследование сектора водоёма, интеграция с картами глубин.

Предполагается использование трёхпозиционного переключателя: **ручное управление / сохранение точки / автопилот**. Точные правила переключения и приоритет ручного управления ещё предстоит согласовать.

## Принципы разработки

1. **Безопасность прежде всего.** Потеря связи с ESP32 или Android не должна приводить к неконтролируемому движению.
2. **Независимость от интерфейса.** STM32 выполняет навигацию локально.
3. **Разделение ответственности.** Wi-Fi и обработка эхолота находятся в отдельных проектах.
4. **Явные протоколы.** Формат обмена STM32 ↔ ESP32 будет описан и версионирован отдельно.
5. **Проверка на стенде.** Перед испытаниями управления двигателем требуется безопасная конфигурация без вращающегося винта.
