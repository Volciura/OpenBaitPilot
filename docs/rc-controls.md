# RC-управление и переключение режимов

## Требуемая новая схема (из обсуждений; НЕ подтверждена загруженным кодом)
- Передатчик **FlySky FS-i6**, приёмник **iA10B**.
- **SWC** — трёхпозиционный переключатель:
  1. **Manual** — ручное управление;
  2. **Save** — сохранение точки;
  3. **Go to point** — отправка на выбранную точку.
- Способ выбора номера точки **нужно перенести из существующего `my_pixhawk.ino`**, а не изобретать заново.
- Исходник `my_pixhawk.ino` может служить источником существующей логики. Пока файл не предоставлен и не проанализирован, нельзя утверждать точную распиновку или алгоритмы.

## Что должно быть определено по коду и стендовым измерениям
| Вопрос | Статус |
| --- | --- |
| Номер канала iA10B для SWC | Не подтверждён |
| Значения PWM/iBUS для каждой позиции | Не подтверждены |
| Выбор точки: канал, кнопка, длительность импульса | Извлечь из `my_pixhawk.ino` |
| Какой фронт SWC запускает сохранение точки | Не подтверждён |
| Можно ли сохранить точку без GPS fix | Нужна политика |
| Приоритет ручного перехвата и переходы при движении | Нужна спецификация |
| Поведение после перезагрузки STM32 | Нужна спецификация |

## Требования к реализации
- Декодировать позиции SWC через **диапазоны**, с фильтрацией дребезга/скачков; конкретные пороги определить по реальным данным.
- Различать **позицию переключателя** и **событие переключения**: нельзя сохранять точку многократно в каждом цикле.
- Не запускать движение из-за невалидного значения канала или при старте контроллера до проверки RC.
- Сохранить возможность ручного управления независимо от Wi-Fi.
- Перед реализацией сверить управление и переключение точек с `my_pixhawk.ino`, если исходник будет предоставлен.

## Предлагаемая модель состояний (НЕ согласованный алгоритм)
Состояния верхнего уровня: `MANUAL`, `SAVE_POINT`, `NAVIGATE_TO_POINT`, `MISSION`, `WAIT`, `RETURN_HOME`, `ERROR`.
Это лишь модель для проектирования: она **не заменяет** числовые значения `FLIGHT_MODE` в `docs/telemetry.md` и требует утверждения правил переходов.

## Проверка по исходнику
См. `docs/source-audit-my-pixhawk.md`. Реальный код использует CH4 для выбора точки, CH5 для сохранения, CH6 для загрузки миссии. SWC-трёхпозиционная схема в нём не реализована. Комментарии RC7/RC8 расходятся с кодом.
